Pricing, cache and compression assumptions

Experiment usage, provenance and limits

API dollar values are modeled estimates; answer generation ran through a Codex subscription. The primary cost comparison prices the application prompt and measured output, excluding Codex's agent instructions/tool envelope. The separate experiment diagnostic prices the complete CLI usage envelope. Output-token usage includes reasoning when reported; reasoning tokens are not added a second time. Prompt counts use a proxy tokenizer. Network and compression times vary with startup/cache conditions. Taxes, regional premiums, Batch/Flex discounts, Fast mode and unknown account-specific terms are excluded. The compression free allowance remaining is unknown; its toggle is a scenario.
